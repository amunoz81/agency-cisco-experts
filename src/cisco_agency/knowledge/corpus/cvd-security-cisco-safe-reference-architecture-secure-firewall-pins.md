SAFE es la arquitectura de referencia de seguridad de Cisco: organiza el diseño por Places in the Network (campus, sucursal, edge, datacenter, nube) y por capacidades (defensa de amenazas, segmentación, control de acceso, visibilidad). Cisco Secure Firewall (Threat Defense) es el punto de aplicación de perímetro/DC (IPS, URL, malware, TLS). Incluye CVDs validados por PIN (Secure Campus, Secure Branch, Secure Edge, Secure Data Center). Base para justificar el firewall y el mapa de controles.
