Guía de diseño del pilar de Seguridad de Red y Nube de la Cisco Zero Trust Architecture. Integra Catalyst 9300 como switch de acceso y punto de aplicación TrustSec/802.1X (autenticación, control de acceso, monitoreo y enforcement), Cisco ISE para autenticación, autorización y asignación dinámica de Security Group Tags, Cisco Secure Firewall para control de acceso basado en roles junto con TrustSec, Secure Network Analytics para visibilidad y detección de amenazas mediante análisis de telemetría, y Cisco Telemetry Broker, que recibe NetFlow del switch Catalyst y del Secure Firewall y lo distribuye al Flow Collector de Secure Network Analytics. El diseño combina segmentación por grupos (TrustSec/SGT), autenticación de dispositivos/usuarios y monitoreo continuo del tráfico para aplicar políticas de confianza cero desde el acceso de campus hasta la nube, con visibilidad este-oeste granular.
