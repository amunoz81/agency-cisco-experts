Guía de diseño del pilar de red y nube del marco Zero Trust de Cisco, enfocada en proteger los recursos on-prem y en la nube y en garantizar acceso seguro y consistente para todos los usuarios que se conectan. Describe el uso de Cisco ISE para autenticación 802.1X de dispositivos que se conectan a la red cableada e inalámbrica, en conjunto con perfiles de Cisco Secure Client (AnyConnect), como base del control de acceso a la red. Aborda la aplicación de políticas de segmentación (TrustSec/SGT) para limitar el movimiento lateral una vez autenticado el dispositivo, y el rol de Secure Access/SSE (SASE) para extender la verificación continua a usuarios remotos y aplicaciones SaaS, evitando el acceso implícito basado únicamente en la ubicación de red. Complementa el pilar de usuario y dispositivo al mover la confianza desde el perímetro de red hacia la verificación continua de cada sesión y flujo, tanto en el datacenter propio como en cargas en nube.
