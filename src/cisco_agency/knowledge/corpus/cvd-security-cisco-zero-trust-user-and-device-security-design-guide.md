Guía de diseño del pilar de usuario y dispositivo del marco Zero Trust de Cisco. Detalla el despliegue de Cisco Duo para autenticación multifactor (MFA), single sign-on (SSO) y autenticación adaptativa basada en riesgo, de forma que cada usuario se verifique de manera continua en cada acceso, no solo al inicio de sesión. Cubre la evaluación de postura de dispositivos administrados y no administrados (parches, cifrado de disco, versión de SO y controles de seguridad) antes de autorizar el acceso a aplicaciones. Describe la integración con Cisco Secure Client (AnyConnect) y la configuración de sus perfiles para habilitar autenticación 802.1X contra Cisco ISE, unificando el control de acceso a la red con la verificación continua del usuario. Es la base práctica de implementación de la primera capa del modelo Zero Trust: garantizar que solo usuarios verificados en dispositivos conformes obtengan acceso, con controles reevaluados de forma continua conforme cambia el riesgo.
