Guía marco que organiza la arquitectura Zero Trust de Cisco en tres pilares complementarios. User and Device Security verifica continuamente la identidad (MFA, SSO y autenticación basada en riesgo con Duo) y evalúa la postura de dispositivos gestionados y no gestionados antes de conceder acceso. Network and Cloud Security protege los recursos de red on-prem y en nube y garantiza acceso seguro para todos los usuarios que se conectan, apoyándose en ISE para autenticación 802.1X de dispositivos (con perfiles de Cisco Secure Client) y en Secure Access/SSE para el acceso remoto. Application and Data Security aplica políticas de acceso granulares a nivel de aplicación (on-prem o en nube) con Duo, protegiendo indirectamente los datos al limitar el acceso a usuarios autorizados sobre dispositivos conformes. Sirve como mapa de referencia hacia las guías de diseño específicas de cada pilar y hacia el mapeo con marcos regulatorios como el modelo de madurez Zero Trust de CISA.
