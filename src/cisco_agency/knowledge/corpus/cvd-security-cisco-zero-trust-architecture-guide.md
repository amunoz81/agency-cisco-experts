Guía de arquitectura que organiza el framework Zero Trust de Cisco en tres pilares: Seguridad de Usuario y Dispositivo (verifica que usuarios y dispositivos sean confiables sin importar la ubicación), Seguridad de Red y Nube (protege recursos on-prem y en la nube, y asegura el acceso de los usuarios que se conectan) y Seguridad de Aplicación y Datos (previene el acceso no autorizado dentro de los entornos de aplicación). Se apoya en tres pilares fundacionales transversales: Plataforma Zero Trust, Automatización y Orquestación de Seguridad, y Visibilidad y Analítica de Seguridad. Usa la metodología SAFE para mapear las capacidades de seguridad a los componentes arquitectónicos y estos, a su vez, al portafolio de productos Cisco (ISE, Duo, Secure Firewall, Secure Access, Secure Network Analytics, entre otros). Sirve como mapa de referencia para posicionar de forma consistente los productos de seguridad de Cisco dentro de una estrategia Zero Trust integral.
