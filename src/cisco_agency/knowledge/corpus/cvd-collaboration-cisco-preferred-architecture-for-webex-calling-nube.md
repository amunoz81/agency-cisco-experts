Webex Calling como control de llamadas en la nube, en despliegue aislado o combinado con colaboración on-prem (Unified CM). Opciones de PSTN y conectividad Private Network Connect (PNC): Internet, Equinix Fabric (Edge Connect) o PNC dedicado para asegurar QoS y baja latencia de voz. Variante Dedicated Instance para clientes que requieren instancia gestionada. Base para dimensionar por usuario/estación, sesiones PSTN concurrentes y modalidad cloud vs híbrida.
